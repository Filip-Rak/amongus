\section{Review Endpoints}

Review endpoints allow users to read product reviews and allow authenticated regular users to create, update, or delete their own reviews.

A user can review only a product they bought and paid for. Reviews are soft-deleted rather than hard-deleted. Product rating statistics are recalculated after review creation, update, or deletion.

Reviews store a small product snapshot field, \texttt{productName}, when they are created. This allows user review listing views to display the reviewed product name without reading the products collection.

\subsection{Review Response Shape}

Review endpoints return the following review shape:

\begin{minted}[frame=single]{json}
{
    "id": "665000000000000000000050",
    "productId": "665000000000000000000010",
    "userId": "665000000000000000000001",
    "productName": "Smart Toaster 3000",
    "rating": 5,
    "title": "Great toaster",
    "comment": "The QR code burn pattern is surprisingly accurate.",
    "createdAt": "2026-05-30T10:00:00.000Z",
    "updatedAt": "2026-05-30T10:00:00.000Z"
}
\end{minted}

Soft-deleted reviews may also contain:

\begin{minted}[frame=single]{json}
{
    "deletedAt": "2026-05-30T10:10:00.000Z"
}
\end{minted}

Public review listing and user review modification endpoints operate on active reviews.

\subsection{Review Product Snapshot}

Each review stores the product name at the time the review is created.

\begin{minted}[frame=single]{json}
{
    "productId": "665000000000000000000010",
    "productName": "Smart Toaster 3000"
}
\end{minted}

\textbf{Important rules:}

\begin{itemize}
    \item \texttt{productId} points to the reviewed product.
    \item \texttt{productName} is copied from the product during review creation.
    \item Later product name changes do not rewrite historical review data.
    \item \texttt{GET /reviews/my} can display product names without reading the products collection.
\end{itemize}

\subsection{Review Status Values}

Reviews may use the following status values internally:

\begin{itemize}
    \item \texttt{active},
    \item \texttt{deleted}.
\end{itemize}

The response shape does not expose the status field directly. Deleted reviews are normally excluded from public review listing.

\subsection{\texttt{GET /products/:productId/reviews}}

\textbf{Access:} Public

\textbf{Description:} Returns a paginated list of active reviews for a product.

\textbf{Path parameters:}

\begin{itemize}
    \item \texttt{productId} --- product ObjectId.
\end{itemize}

\textbf{Query parameters:}

\begin{itemize}
    \item \texttt{page} --- optional positive integer, default: \texttt{1}.
    \item \texttt{limit} --- optional positive integer, default: \texttt{20}, maximum: \texttt{100}.
\end{itemize}

\textbf{Important rules:}

\begin{itemize}
    \item The product must exist and be active.
    \item Only active reviews are returned.
    \item Reviews are sorted from newest to oldest.
    \item Review items include \texttt{productName} as a product name snapshot.
\end{itemize}

\textbf{Example request:}

\begin{minted}[frame=single]{http}
GET /products/665000000000000000000010/reviews?page=1&limit=20
\end{minted}

\pagebreak
\textbf{Example success response:}

\begin{minted}[frame=single]{json}
{
    "items": [
        {
            "id": "665000000000000000000050",
            "productId": "665000000000000000000010",
            "userId": "665000000000000000000001",
            "productName": "Smart Toaster 3000",
            "rating": 5,
            "title": "Great toaster",
            "comment": "The QR code burn pattern is surprisingly accurate.",
            "createdAt": "2026-05-30T10:00:00.000Z",
            "updatedAt": "2026-05-30T10:00:00.000Z"
        }
    ],
    "page": 1,
    "limit": 20,
    "total": 1,
    "totalPages": 1
}
\end{minted}

\subsection{\texttt{GET /reviews/my}}

\textbf{Access:} Authenticated regular user

\textbf{Description:} Returns a paginated list of active reviews created by the currently authenticated user.

\textbf{Headers:}

\begin{minted}[frame=single]{http}
Authorization: Bearer <accessToken>
\end{minted}

\textbf{Query parameters:}

\begin{itemize}
    \item \texttt{page} --- optional positive integer, default: \texttt{1}.
    \item \texttt{limit} --- optional positive integer, default: \texttt{20}, maximum: \texttt{100}.
\end{itemize}

\textbf{Important rules:}

\begin{itemize}
    \item Only users with the \texttt{user} role can use this endpoint.
    \item The endpoint returns only reviews owned by the authenticated user.
    \item Only active reviews are returned.
    \item Reviews are sorted from newest to oldest.
    \item The response includes \texttt{productName}, which was saved when the review was created.
    \item The endpoint can serve a simple user reviews view without reading product documents.
\end{itemize}

\textbf{Example request:}

\begin{minted}[frame=single]{http}
GET /reviews/my?page=1&limit=20
Authorization: Bearer <accessToken>
\end{minted}

\textbf{Example success response:}

\begin{minted}[frame=single]{json}
{
    "items": [
        {
            "id": "665000000000000000000050",
            "productId": "665000000000000000000010",
            "userId": "665000000000000000000001",
            "productName": "Smart Toaster 3000",
            "rating": 5,
            "title": "Great toaster",
            "comment": "The QR code burn pattern is surprisingly accurate.",
            "createdAt": "2026-05-30T10:00:00.000Z",

    "page": 1,

\end{minted}

\subsection{\texttt{POST /products/:productId/reviews}}

\textbf{Access:} Authenticated regular user

\textbf{Description:} Creates a review for a product.

\textbf{Path parameters:}

\begin{itemize}
    \item \texttt{productId} --- product ObjectId.
\end{itemize}

\textbf{Headers:}

\begin{minted}[frame=single]{http}
Authorization: Bearer <accessToken>
Content-Type: application/json
\end{minted}

\textbf{Request body:}

\begin{minted}[frame=single]{json}
{
    "rating": 5,
    "title": "Great toaster",
    "comment": "The QR code burn pattern is surprisingly accurate."
}
\end{minted}

\textbf{Body fields:}

\begin{itemize}
    \item \texttt{rating} --- required integer from \texttt{1} to \texttt{5}.
    \item \texttt{title} --- optional non-empty string.
    \item \texttt{comment} --- optional non-empty string.
\end{itemize}

\textbf{Important rules:}

\begin{itemize}
    \item Only users with the \texttt{user} role can create reviews.
    \item The product must exist and be active.
    \item The product name is saved into the review as \texttt{productName}.
    \item The user must have a paid, shipped, or completed order containing the reviewed product.
    \item A user can have only one active review per product.
    \item If a previous review was deleted, creating a new active review for the same product is allowed.
    \item After review creation, product \texttt{averageRating} and \texttt{reviewCount} are recalculated.
\end{itemize}

\textbf{Example request:}

\begin{minted}[frame=single]{http}
POST /products/665000000000000000000010/reviews
Authorization: Bearer <accessToken>
Content-Type: application/json
\end{minted}

\begin{minted}[frame=single]{json}
{
    "rating": 5,
    "title": "Great toaster",
    "comment": "The QR code burn pattern is surprisingly accurate."
}
\end{minted}

\pagebreak
\textbf{Example success response:}

\begin{minted}[frame=single]{json}
{
    "id": "665000000000000000000050",
    "productId": "665000000000000000000010",
    "userId": "665000000000000000000001",
    "productName": "Smart Toaster 3000",
    "rating": 5,
    "title": "Great toaster",
    "comment": "The QR code burn pattern is surprisingly accurate.",
    "createdAt": "2026-05-30T10:00:00.000Z",
    "updatedAt": "2026-05-30T10:00:00.000Z"
}
\end{minted}

\textbf{Example failure when the product was not bought and paid for:}

\begin{minted}[frame=single]{json}
{
    "message": "You can review only products you have bought and paid for",
    "error": "Forbidden",
    "statusCode": 403
}
\end{minted}

\textbf{Example failure when the user already has an active review:}

\begin{minted}[frame=single]{json}
{
    "message": "You have already reviewed this product",
    "error": "Conflict",
    "statusCode": 409
}
\end{minted}

\subsection{\texttt{PATCH /reviews/:id}}

\textbf{Access:} Authenticated regular user

\textbf{Description:} Updates the authenticated user's own active review.

\textbf{Path parameters:}

\begin{itemize}
    \item \texttt{id} --- review ObjectId.
\end{itemize}

\textbf{Headers:}

\begin{minted}[frame=single]{http}
Authorization: Bearer <accessToken>
Content-Type: application/json
\end{minted}

\pagebreak
\textbf{Request body:}

\begin{minted}[frame=single]{json}
{
    "rating": 4,
    "title": "Updated review title",
    "comment": "Updated review comment."
}
\end{minted}

\textbf{Body fields:}

\begin{itemize}
    \item \texttt{rating} --- optional integer from \texttt{1} to \texttt{5}.
    \item \texttt{title} --- optional non-empty string.
    \item \texttt{comment} --- optional non-empty string.
\end{itemize}

\textbf{Important rules:}

\begin{itemize}
    \item At least one editable field must be provided.
    \item Only the owner of the review can update it.
    \item Only active reviews can be updated.
    \item \texttt{productName} is not editable through this endpoint.
    \item After review update, product \texttt{averageRating} and \texttt{reviewCount} are recalculated.
\end{itemize}

\textbf{Example request:}

\begin{minted}[frame=single]{http}
PATCH /reviews/665000000000000000000050
Authorization: Bearer <accessToken>
Content-Type: application/json
\end{minted}

\begin{minted}[frame=single]{json}
{
    "rating": 4,
    "comment": "Updated review comment."
}
\end{minted}

\textbf{Example success response:}

\begin{minted}[frame=single]{json}
{
    "id": "665000000000000000000050",
    "productId": "665000000000000000000010",
    "userId": "665000000000000000000001",
    "productName": "Smart Toaster 3000",
    "rating": 4,
    "title": "Great toaster",
    "comment": "Updated review comment.",
    "createdAt": "2026-05-30T10:00:00.000Z",
    "updatedAt": "2026-05-30T10:15:00.000Z"
}
\end{minted}

\textbf{Example failure when editing another user's review:}

\begin{minted}[frame=single]{json}
{
    "message": "You cannot modify this review",
    "error": "Forbidden",
    "statusCode": 403
}
\end{minted}

\subsection{\texttt{DELETE /reviews/:id}}

\textbf{Access:} Authenticated regular user

\textbf{Description:} Soft-deletes the authenticated user's own active review.

\textbf{Path parameters:}

\begin{itemize}
    \item \texttt{id} --- review ObjectId.
\end{itemize}

\textbf{Headers:}

\begin{minted}[frame=single]{http}
Authorization: Bearer <accessToken>
\end{minted}

\textbf{Request body:} None.

\textbf{Important rules:}

\begin{itemize}
    \item Only the owner of the review can delete it.
    \item Only active reviews can be deleted.
    \item The review status is changed to \texttt{deleted}.
    \item The review receives a \texttt{deletedAt} timestamp.
    \item After review deletion, product \texttt{averageRating} and \texttt{reviewCount} are recalculated.
    \item Successful deletion returns \texttt{204 No Content}.
\end{itemize}

\textbf{Example request:}

\begin{minted}[frame=single]{http}
DELETE /reviews/665000000000000000000050
Authorization: Bearer <accessToken>
\end{minted}

\subsection{\texttt{DELETE /reviews/admin/:id}}

\textbf{Access:} Administrator

\textbf{Description:} Soft-deletes any active review as an administrator.

\textbf{Path parameters:}

\begin{itemize}
    \item \texttt{id} --- review ObjectId.
\end{itemize}

\textbf{Headers:}

\begin{minted}[frame=single]{http}
Authorization: Bearer <adminAccessToken>
\end{minted}

\textbf{Request body:} None.

\textbf{Important rules:}

\begin{itemize}
    \item Only administrators can use this endpoint.
    \item Only active reviews can be deleted.
    \item The review status is changed to \texttt{deleted}.
    \item The review receives a \texttt{deletedAt} timestamp.
    \item After review deletion, product \texttt{averageRating} and \texttt{reviewCount} are recalculated.
    \item Successful deletion returns \texttt{204 No Content}.
\end{itemize}

\textbf{Example request:}

\begin{minted}[frame=single]{http}
DELETE /reviews/admin/665000000000000000000050
Authorization: Bearer <adminAccessToken>
\end{minted}

    "statusCode": 404

\end{minted}

    "message": "Review not found",
    "error": "Not Found",
    "statusCode": 404
}
\end{minted}

    "message": "You can review only products you have bought and paid for",
    "error": "Forbidden",
    "statusCode": 403
}
\end{minted}
