\section{Order Endpoints}

Order endpoints allow authenticated regular users to create orders from their cart and view their own orders.

The current API exposes only user-owned order operations. There are no administrator order management endpoints in the current version.

Checkout supports both private and company purchases. Invoice-related data is stored directly as part of the order snapshot. The API does not create a separate invoice resource.

\subsection{Purchase Type Values}

Orders may use the following purchase type values:

\begin{itemize}
    \item \texttt{private},
    \item \texttt{company}.
\end{itemize}

If \texttt{purchaseType} is omitted during checkout, the backend treats the order as a private purchase.

\subsection{Invoice Snapshot Shape}

Invoice data is stored as an order snapshot. It is not a separate resource and does not create a legal invoice document by itself.

A private purchase without invoice request uses the following shape:

\begin{minted}[frame=single]{json}
{
    "requested": false,
    "billingAddressSameAsShipping": true
}
\end{minted}

\pagebreak
A company purchase with invoice request may use the following shape:

\begin{minted}[frame=single]{json}
{
    "requested": true,
    "billingAddressSameAsShipping": false,
    "billingAddress": {
        "fullName": "ACME Sp. z o.o.",
        "line1": "Business Street 1",
        "city": "Warsaw",
        "postalCode": "00-002",
        "country": "Poland"
    },
    "companyDetails": {
        "companyName": "ACME Sp. z o.o.",
        "taxId": "1234567890"
    }
}
\end{minted}

\textbf{Invoice fields:}

\begin{itemize}
    \item \texttt{requested} --- boolean indicating whether invoice data was requested.
    \item \texttt{billingAddressSameAsShipping} --- boolean indicating whether the shipping address should also be used as the billing address.
    \item \texttt{billingAddress} --- optional billing address object. Required when invoice is requested and billing address is not the same as shipping address.
    \item \texttt{companyDetails} --- optional company details object. Required for company purchases.
\end{itemize}

\textbf{Company details fields:}

\begin{itemize}
    \item \texttt{companyName} --- required string for company purchases.
    \item \texttt{taxId} --- required string for company purchases.
\end{itemize}

\textbf{Important rules:}

\begin{itemize}
    \item Company purchases require \texttt{invoice.requested} to be \texttt{true}.
    \item Company purchases require \texttt{invoice.companyDetails}.
    \item Private purchases cannot include company details.
    \item If invoice is not requested, billing address data is not required.
    \item If invoice is requested and \texttt{billingAddressSameAsShipping} is \texttt{true}, the shipping address is used as the billing address.
    \item If invoice is requested and \texttt{billingAddressSameAsShipping} is \texttt{false}, \texttt{billingAddress} is required.
\end{itemize}

\subsection{Order Item Snapshot}

Order items are stored as product snapshots. This means the order keeps selected product data from the time of checkout.

\begin{minted}[frame=single]{json}
{
    "productId": "665000000000000000000010",
    "productName": "Smart Toaster 3000",
    "productSlug": "smart-toaster-3000",
    "unitPriceAmount": 24999,
    "currency": "PLN",
    "quantity": 2,
    "imageUrl": "https://example.com/toaster.jpg"
}
\end{minted}

\textbf{Important rules:}

\begin{itemize}
    \item \texttt{productId} points to the product.
    \item \texttt{productName}, \texttt{productSlug}, \texttt{unitPriceAmount}, \texttt{currency}, and \texttt{imageUrl} are copied into the order during checkout.
    \item Later product edits do not rewrite historical order item data.
\end{itemize}

\subsection{Shipping Address Shape}

Checkout requires a shipping address.

\begin{minted}[frame=single]{json}
{
    "fullName": "Jan Kowalski",
    "line1": "Example Street 12",
    "line2": "Apartment 4",
    "city": "Warsaw",
    "postalCode": "00-001",
    "country": "Poland",
    "phone": "+48123456789"
}
\end{minted}

\textbf{Shipping address fields:}

\begin{itemize}
    \item \texttt{fullName} --- required string.
    \item \texttt{line1} --- required string.
    \item \texttt{line2} --- optional string.
    \item \texttt{city} --- required string.
    \item \texttt{postalCode} --- required string.
    \item \texttt{country} --- required string.
    \item \texttt{phone} --- optional string.
\end{itemize}

The same address shape is also used for invoice billing addresses.

\subsection{Order Totals Shape}

\begin{minted}[frame=single]{json}
{
    "subtotalAmount": 49998,
    "shippingAmount": 0,
    "totalAmount": 49998,
    "currency": "PLN"
}
\end{minted}

\textbf{Total fields:}

\begin{itemize}
    \item \texttt{subtotalAmount} --- sum of item prices before shipping.
    \item \texttt{shippingAmount} --- shipping cost.
    \item \texttt{totalAmount} --- final amount to be paid.
    \item \texttt{currency} --- order currency.
\end{itemize}

The current checkout implementation uses \texttt{0} as the shipping amount.

\subsection{Order Status Values}

Orders may use the following status values:

\begin{itemize}
    \item \texttt{pending\_payment},
    \item \texttt{paid},
    \item \texttt{payment\_failed},
    \item \texttt{cancelled},
    \item \texttt{shipped},
    \item \texttt{completed}.
\end{itemize}

\subsection{\texttt{POST /orders/checkout}}

\textbf{Access:} Authenticated regular user

\textbf{Description:} Creates an order from the current user's cart and creates a pending mock payment for that order.

\textbf{Headers:}

\begin{minted}[frame=single]{http}
Authorization: Bearer <accessToken>
Content-Type: application/json
\end{minted}

\pagebreak
\textbf{Minimal private purchase request body:}

\begin{minted}[frame=single]{json}
{
    "shippingAddress": {
        "fullName": "Jan Kowalski",
        "line1": "Example Street 12",
        "line2": "Apartment 4",
        "city": "Warsaw",
        "postalCode": "00-001",
        "country": "Poland",
        "phone": "+48123456789"
    }
}
\end{minted}

\textbf{Private purchase with invoice request body:}

\begin{minted}[frame=single]{json}
{
    "purchaseType": "private",
    "invoice": {
        "requested": true,
        "billingAddressSameAsShipping": true
    },
    "shippingAddress": {
        "fullName": "Jan Kowalski",
        "line1": "Example Street 12",
        "city": "Warsaw",
        "postalCode": "00-001",
        "country": "Poland"
    }
}
\end{minted}

\pagebreak
\textbf{Company purchase request body:}

\begin{minted}[frame=single]{json}
{
    "purchaseType": "company",
    "invoice": {
        "requested": true,
        "billingAddressSameAsShipping": false,
        "billingAddress": {
            "fullName": "ACME Sp. z o.o.",
            "line1": "Business Street 1",
            "city": "Warsaw",
            "postalCode": "00-002",
            "country": "Poland"
        },
        "companyDetails": {
            "companyName": "ACME Sp. z o.o.",
            "taxId": "1234567890"
        }
    },
    "shippingAddress": {
        "fullName": "Warehouse Receiver",
        "line1": "Warehouse Street 5",
        "city": "Warsaw",
        "postalCode": "00-003",
        "country": "Poland",
        "phone": "+48123456789"
    }
}
\end{minted}

\textbf{Body fields:}

\begin{itemize}
    \item \texttt{purchaseType} --- optional enum: \texttt{private}, \texttt{company}. Defaults to \texttt{private}.
    \item \texttt{invoice} --- optional object containing invoice request data.
    \item \texttt{invoice.requested} --- optional boolean. Defaults to \texttt{false}.
    \item \texttt{invoice.billingAddressSameAsShipping} --- optional boolean. Defaults to \texttt{true}.
    \item \texttt{invoice.billingAddress} --- optional address object. Required when invoice is requested and billing address is not the same as shipping address.
    \item \texttt{invoice.companyDetails} --- optional company details object. Required for company purchases.
    \item \texttt{invoice.companyDetails.companyName} --- required string for company purchases.
    \item \texttt{invoice.companyDetails.taxId} --- required string for company purchases.
    \item \texttt{shippingAddress} --- required object containing the shipping address.
    \item \texttt{shippingAddress.fullName} --- required string.
    \item \texttt{shippingAddress.line1} --- required string.
    \item \texttt{shippingAddress.line2} --- optional string.
    \item \texttt{shippingAddress.city} --- required string.
    \item \texttt{shippingAddress.postalCode} --- required string.
    \item \texttt{shippingAddress.country} --- required string.
    \item \texttt{shippingAddress.phone} --- optional string.
\end{itemize}

\textbf{Important rules:}

\begin{itemize}
    \item The user must have a non-empty cart.
    \item Every cart product must still exist and be active.
    \item Every cart item quantity must be available in stock.
    \item Checkout with multiple currencies is rejected.
    \item Product stock is decreased during checkout.
    \item The cart is cleared after successful checkout.
    \item The created order starts with status \texttt{pending\_payment}.
    \item Checkout also creates a pending mock payment.
    \item Company purchases require invoice data and company details.
    \item Private purchases cannot include company details.
    \item Billing address may be copied from shipping address.
    \item The operation is transactional: order creation, payment creation, stock changes, and cart clearing are handled together.
\end{itemize}

\subsection{\texttt{GET /orders/my}}

\textbf{Access:} Authenticated regular user

\textbf{Description:} Returns all orders owned by the currently authenticated user.

\textbf{Headers:}

\begin{minted}[frame=single]{http}
Authorization: Bearer <accessToken>
\end{minted}

\textbf{Request body:} None.

\textbf{Important rules:}

\begin{itemize}
    \item The endpoint returns only orders belonging to the authenticated user.
    \item Orders are returned from newest to oldest.
\end{itemize}

\textbf{Example request:}

\begin{minted}[frame=single]{http}
GET /orders/my
Authorization: Bearer <accessToken>
\end{minted}

\subsection{\texttt{GET /orders/:id}}

\textbf{Access:} Authenticated regular user

\textbf{Description:} Returns one order owned by the currently authenticated user.

\textbf{Path parameters:}

\begin{itemize}
    \item \texttt{id} --- order ObjectId.
\end{itemize}

\textbf{Headers:}

\begin{minted}[frame=single]{http}
Authorization: Bearer <accessToken>
\end{minted}

\textbf{Request body:} None.

\textbf{Important rules:}

\begin{itemize}
    \item The endpoint returns only an order belonging to the authenticated user.
    \item If the order does not exist or belongs to another user, the response is \texttt{404 Not Found}.
\end{itemize}

\textbf{Example request:}

\begin{minted}[frame=single]{http}
GET /orders/665000000000000000000030
Authorization: Bearer <accessToken>
